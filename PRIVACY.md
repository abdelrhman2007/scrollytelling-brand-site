# Privacy policy

**scrollytelling-brand-site** is a Claude skill: a set of instructions, reference documents, screenshots and template
files that Claude reads while helping you build a website.

- It **collects no data**. It contains no MCP servers, no hooks, no scripts that run on install, no analytics and no
  network calls.
- It sends nothing to the author or to any third party.
- Anything you share while using it (for example a company profile) stays within your normal use of Claude and is
  governed by Anthropic's privacy policy, not by this project.
- Websites you build with it are your own; their privacy obligations are yours to define.

Questions: open an issue at https://github.com/abdelrhman2007/scrollytelling-brand-site/issues
